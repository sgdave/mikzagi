### Folders and organization
- 0_Inbox  
  Where raw, messy, untagged notes live. Logs from PC, vacation and (for now) only raw text data goes here.
- 1_Processing
Temporary workspace for sorting what comes from Inbox → Areas, Projects, Resources. Act's as an interface between the raw data and the primary MIKZAGI layer.
- 2_Areas
Your key life pillars.
Each is ongoing and never really “done.”
Not sure yet what this folder will contain, but could just be material or data relevant to life. Financial seeems a good place to start.
- 3_Projects
Short-term linked-actions with an end point and a success criteria for reviews. Project specific material lives here (this can be unified later, but easier to start separate)
- 4_Resources
Long-term reference material (guides, research, templates, quotes, manuals)
Non project specific only.
- 5_Reviews
Reviews conducted on a recurring basis to evaluate progress.
